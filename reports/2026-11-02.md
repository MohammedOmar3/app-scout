## Notes

- The daily collection was fully healthy today (250 apps, no blocked shards), and the first targeted run wasn't soft-blocked either, unlike yesterday.
- **Targeted storefront pool is too narrow for apps that chart in only a few storefronts.** `scan_app` tries `search_storefronts + all_storefronts + ratings_cc + us, gb`, so Untappd (charts only in us/gb) can never be read in ca, au, ie, nz, de or nl, even with `--storefronts-per-app 8`. Apps that chart only in small storefronts get hr/rs/si/sk/lt/lv instead of the big English ones. Suggestion: in targeted mode, add a fallback list (ca, au, ie, nz, de, nl, fr, se) to the end of the pool.
